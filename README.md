# MobileNVR

Maqueta inicial de una app móvil para gestionar grabaciones DVR/NVR. Incluye búsqueda rápida, tarjetas de eventos recientes, línea de tiempo y barra de navegación inferior para visualizar cámaras y acciones frecuentes.

## Requisitos
- Node.js 20+
- npm

## Scripts
- `npm install` para instalar dependencias.
- `npm run dev` para iniciar el entorno de desarrollo con Vite.
- `npm run build` para generar la versión de producción.
- `npm run preview` para previsualizar la versión compilada.
- `npm run lint` para revisar el código con ESLint.
